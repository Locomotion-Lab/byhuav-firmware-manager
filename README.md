# BYHUAV 板卡固件迁移工具

在外部 Windows、Linux 或 macOS 电脑上，将兼容的 BYHUAV 板卡从 1.x 迁移到随附的 2.0.0 固件。

**验证状态：macOS 已完成本次实板升级验收；Windows / Linux 实板测试待完成。** 具体范围见 [实板验证记录](docs/实板验证记录.md)。

使用说明见 **[板卡固件升级教程（可导入语雀）](docs/语雀教程.md)**。

工具按顺序完成 ESP32 备份与更新、STM32 Core 更新、STM32 Bootloader 更新，并在两次物理重启时提供提示。用户需要按提示核对设备、操作 USB、检查网页和灯光。系统镜像烧录、设备注册使用各自独立教程。

| 随附固件 | 目标版本 |
| --- | --- |
| ESP32-S3 应用 | 2.0.0 / `6e39ffb4` |
| STM32 Core | 2.0.0 / `95e901b4` |
| STM32 Bootloader | 随包固定文件；没有可查询的版本号 |

仅适用于有兼容 ESP32 Bootloader/分区表、可识别的 U29 USB 设备和原有约 32 GB SD 卡的板卡。工具会拒绝不兼容设备。空白芯片和损坏设备需要维护人员使用工厂恢复包。

维护与验证说明见 [维护说明](docs/维护说明.md)。
